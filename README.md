# Enterprise Operations Intelligence Platform

An AI-powered enterprise operations intelligence system that investigates
business and operational problems using company documents, databases,
Jira, GitHub, and other enterprise data sources.

## Tech Stack

- Python
- LangChain
- LangGraph
- Gemini
- ChromaDB
- PostgreSQL
- FastAPI
- Streamlit
- Docker
- GitHub

## Project Goal

Build an AI operations analyst capable of:

- Retrieving information from enterprise documents
- Querying structured databases
- Investigating Jira issues
- Analyzing GitHub activity
- Connecting evidence across multiple sources
- Performing root-cause analysis
- Providing citations and recommendations
- Enforcing role-based access control
